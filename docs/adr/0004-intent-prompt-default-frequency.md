# Intent Prompt default: reflexive-use trigger only

A fresh install shows the Intent Prompt only on the reflexive-use pattern: it fires at the start of the 3rd session within a 15-minute rolling window, then observes a 30-minute cooldown. Counting uses sessions, not raw unlocks — the merge window (ADR 0001) already absorbs accidental relocks. All other spec triggers default off: every-session remains the explicit "ask every time" setting; distracting-app and selected-unlocks triggers stay off until the user configures them; "no active task" acts as a suppression gate, never an independent trigger (as a trigger it would fire on nearly every session). There is no first-session-of-day prompt — Today's empty intention card owns that moment (ADR 0003). The three numbers ship fixed in v1 and become the Settings defaults later. Alternatives rejected: every-session default (becomes a swipe-away reflex), once-daily default (redundant with Today). Resolved in issue #35.
