# Free vs Pro: freemium with the core loop free forever

Bodha is freemium — no trial-then-paywall. A launcher is infrastructure: hard-paywalling the home screen forces an uninstall-or-pay moment at maximum resentment, and free anchors (Olauncher, ScreenZen) make a basic intentional launcher an expected free good. Pro is depth on the blocker-like features, gated by the single `bodha_pro` entitlement (RevenueCat). Whether Pro gets an intro trial is a pricing question (issue #38), not a boundary one. Market survey: `docs/research/pricing-competitors.md` on branch `research/pricing` (issue #37). Resolved in issue #36.

**Free, uncapped:** Home, Universal Search, App Library, gestures, Intent Prompt (the central loop never sits behind the paywall), Today + daily intention, notifications inbox, basic context modes, basic themes, single ad-hoc Focus session.

**Free, capped:** Open Check — 3 rules (market caps at 1; 3 proves the feature, power users hit the wall); Awareness — 7-day view.

**Pro:** unlimited Open Check rules; Focus scheduling, profiles, and recurring sessions; full Awareness history; Reflection; advanced context suggestions; advanced themes; encrypted sync/backup; external connectors (Todoist, Home Assistant, Google Calendar API); and — contingent on issues #39/#40 — notification summaries and any cloud AI features, which are Pro if they ship at all.
