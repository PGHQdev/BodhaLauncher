# Minimum SDK: API 29 (Android 10)

Bodha v1 ships with minSdk 29. RoleManager/ROLE_HOME (API 29+) is the only mechanism that gives the clean one-tap "set as default launcher" prompt — the make-or-break first-run step for a launcher — and API 29+ covers 91.1% of active devices (Apr 2026, Statcounter). Dropping to 26 would add ~5 points of coverage but forces a worse fallback (HOME-intent chooser / Settings deep link) on exactly that step; as a paid product Bodha's audience skews toward newer devices, so the effective loss is smaller still. App discovery uses a `<queries>` filter (MAIN + LAUNCHER), never QUERY_ALL_PACKAGES. Full survey: `docs/research/min-sdk.md` on branch `research/min-sdk`, resolved in issue #31.

**Revisit trigger:** if post-launch install-funnel or support data shows meaningful demand from API 26–28 devices, reconsider adding the pre-29 fallback flow as a fresh effort.
