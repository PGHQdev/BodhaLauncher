# No cloud AI at v1: fully on-device

v1 ships with no cloud AI. Of the AI Assist spec's capabilities (#13), everything on the MVP path is deterministic or a local heuristic — resume cards, app-switching detection, meeting actions, templated reflections, command parsing, query classification. The only capability that genuinely wants a language model is notification summaries, which is decided separately (#40) under this constraint: on-device model where available, or degrade. Staying on-device keeps the privacy story absolute ("nothing leaves your phone") — compounding with the analytics positioning, the Play Data Safety form, and the no-manipulation paywall stance — and avoids provider choice, consent UX, backend cost, and per-user inference margin on a $20/yr product. Monetization does not depend on this: every ADR 0005 Pro feature is deterministic. Cloud AI remains a possible post-launch Pro feature (Pro if it ever ships, per ADR 0005), revisited as a fresh effort. Resolved in issue #39.
