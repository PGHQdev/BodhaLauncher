# Daily intention: expires at 4am local, clears rather than carries over

The daily intention persists from when it is set until the next 4:00am local time, surviving sessions, reboots, and process death. At the boundary it clears — Today shows the empty "set today's intention" state — with yesterday's text offered as a one-tap suggestion when setting a new one; the card never shows stale content. It is editable and clearable anytime during the day; replacing overwrites, with no intra-day history in v1. Expiry is computed from a stored local day key (local date shifted by −4h), so an intention set at 1am belongs to the previous evening's day and expires at the next 4am, and travel/DST resolve deterministically from the local wall clock. Alternatives rejected: plain-midnight reset (vanishes mid-late-night-session), carry-over-as-stale (turns a daily practice into a static label), and sleep-inferred reset (unpredictable, hard to explain). Resolved in issue #34.
